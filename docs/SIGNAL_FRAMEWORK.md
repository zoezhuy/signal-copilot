# Recruiting Communication Signal Framework

本框架定义的是**沟通信号**，不是候选人属性或就业决策标签。每个信号必须由可引用文本支持，并允许人工推翻。

| 信号类别 | 适用模式 | 可观察证据 | 不应推断 | 推荐动作 |
|---|---|---|---|---|
| 明确下一步 | 求职者 | 下一轮、面试官、日历邀请 | 一定会录用 | 确认时间并准备问题 |
| 具体时间线 | 双方 | 日期、答复日、签约或入职时间 | 对方绝不会改变计划 | 记录并在约定时间跟进 |
| 流程模糊 | 求职者 | 无明确时间、仍在面试、流程暂停 | 已经被拒绝 | 询问预计节点，继续其他机会 |
| 明确拒绝 | 求职者 | 不再推进、选择其他候选人 | 候选人能力不足 | 专业收尾并寻求反馈 |
| 积极意愿 | 招聘方 | 期待加入、愿意签约、确认入职 | 必然接受 Offer | 及时完成合同及入职沟通 |
| 竞品 Offer | 招聘方 | 其他 Offer、截止时间 | 候选人不忠诚 | 澄清优先因素并协调时间 |
| 薪资顾虑 | 招聘方 | 基本工资、总包、期望差距 | 只要加薪就会接受 | 了解具体差距和非薪资因素 |
| 决策时间 | 招聘方 | 需要考虑、与家人商量 | 缺乏兴趣 | 约定合理答复时间并开放答疑 |
| 入职时间 | 招聘方 | 无法确认、需延后入职 | 不会入职 | 澄清约束并协商替代日期 |
| 回复延迟 | 双方 | 带时间戳的响应间隔 | 兴趣低或不专业 | 结合阶段、时区和约定节奏判断 |

## 证据等级

- **直接证据**：对方明确表达决定、下一步或顾虑。
- **间接证据**：需要结合上下文解释的措辞或行为。
- **缺失证据**：信息不足；产品应提示补充内容，而不是补全事实。

## 输出原则

1. 信号标题必须能在原文中找到对应证据。
2. 风险只描述需要澄清的沟通状态，不评价人。
3. 单一间接信号不得形成高风险结论。
4. 回复延迟必须依赖时间戳，不能从消息正文凭空推断。
5. 建议必须是合法、尊重且可执行的沟通动作。
